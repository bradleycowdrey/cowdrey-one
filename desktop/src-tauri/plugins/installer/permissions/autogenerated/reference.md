## Default Permission

Lets Cowdrey One's web app call the installer's native methods (see METHODS in src/lib.rs).

#### This default permission set includes the following:

- `allow-native`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`installer:allow-native`

</td>
<td>

</td>
</tr>

<tr>
<td>

</td>

</td>
